# Aldridge & Sons Interiors — Mock Demo Site

A single self-contained `index.html` demo site for a fictional interior
plasterwork company, built to show how quickly a first website can go
together. Sells covings, ceiling roses, fireplace surrounds, corbels and trim.

No build step, no dependencies, no external images — everything is plain
HTML/CSS/JS in one file. Just open `index.html` in a browser, or serve the
folder with any static file server:

```
cd dad-interiors-site
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

All business details (name, phone, address, reviews) are fictional
placeholders for demo purposes only.
